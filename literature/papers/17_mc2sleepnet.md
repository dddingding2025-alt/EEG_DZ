# MC2SleepNet: Multi-modal Cross-masking with Contrastive Learning for Sleep Stage Classification

- 年份/状态：2025，arXiv。
- 链接：https://arxiv.org/abs/2502.17470
- 任务：结合 raw EEG 和 spectrogram 的多模态睡眠分期。
- 贡献：用 cross-masking 与 contrastive learning 强化不同视角协作。
- 对本项目的价值：说明时域/频域互补仍有价值，但应放入泛化或少标签设置。
- 局限：若没有跨数据集和阶段级误差分析，难以证明临床鲁棒性。
