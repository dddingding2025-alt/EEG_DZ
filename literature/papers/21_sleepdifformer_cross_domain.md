# Multi-Channel Differential Transformer for Cross-Domain Sleep Stage Classification

- 年份/状态：2025，arXiv。
- 链接：https://arxiv.org/abs/2508.15215
- 任务：异构 EEG/EOG 的跨域睡眠分期。
- 贡献：把多数据集作为源域，学习面向未知目标域的 domain-invariant 表示。
- 对本项目的价值：直接支撑后续采用 leave-one-dataset-out 或 multi-source DG 评测。
- 局限：跨域方法容易受预处理、通道选择和目标域组成影响，需严格消融。
