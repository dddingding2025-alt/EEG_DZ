# Towards Multi-Source Domain Generalization for Sleep Staging with Noisy Labels / FF-TRUST

- 年份/状态：2026，arXiv。
- 链接：https://arxiv.org/abs/2604.10009
- 任务：同时处理多源域泛化和 noisy labels 的睡眠分期。
- 贡献：明确把 domain shift 与 label noise 放在同一个 benchmark/方法框架中。
- 对本项目的价值：几乎正中推荐方向，可作为下一步研究的最重要近邻工作和竞争基线。
- 局限：需要核查代码、数据划分和噪声设定是否公开且可复现。
