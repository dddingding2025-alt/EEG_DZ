# STDA-Net: Spectrogram-Based Domain Adaptation for Cross-Dataset Sleep Stage Classification

- 年份/状态：2026，arXiv。
- 链接：https://arxiv.org/abs/2605.06736
- 任务：跨数据集 EEG 睡眠分期的无监督域适配。
- 贡献：将 spectrogram、BiLSTM 和 DANN 结合，在 Sleep-EDF 与 SHHS 设置下验证跨数据集适配。
- 对本项目的价值：可作为跨数据集评测协议和 domain adaptation baseline 的参考。
- 局限：频谱图方法是否对可穿戴低质量 EEG 稳定，还需单独验证。
