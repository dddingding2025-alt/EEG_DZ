# Next-Token Prediction Learns Generalisable Representations of Sleep Physiology / Hypnos

- 年份/状态：2026，arXiv。
- 链接：https://arxiv.org/abs/2606.09605
- 任务：用 next-token prediction 学习多模态睡眠生理 foundation model。
- 贡献：把语言模型式 next-token prediction 引入睡眠生理信号，并强调少标签睡眠分期。
- 对本项目的价值：代表 2026 最新方向，说明 sleep foundation model 正在从 masked/contrastive 扩展到 autoregressive token modeling。
- 局限：模型规模和数据门槛很高，短期不适合从零复现。
