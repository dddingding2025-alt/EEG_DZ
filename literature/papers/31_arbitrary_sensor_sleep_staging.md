# Generative Pretrained Model for Sleep Stage Classification With Arbitrary Sensor Input

- 年份/状态：2024，arXiv。
- 链接：https://arxiv.org/abs/2408.15253
- 任务：用生成式预训练处理任意传感器输入的睡眠分期。
- 贡献：把传感器缺失、通道异构和多模态输入纳入统一模型框架。
- 对本项目的价值：支撑“居家/可穿戴睡眠分期不是固定通道分类问题”，而是异构传感器鲁棒建模问题。
- 局限：任意传感器模型需要严格测试缺失模式、低质量信号和外部数据集，否则容易只体现工程复杂度。
