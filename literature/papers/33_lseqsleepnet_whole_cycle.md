# L-SeqSleepNet: Whole-cycle Long Sequence Modelling for Automatic Sleep Staging

- 年份/状态：2023，arXiv；已发表于 IEEE JBHI。
- 链接：https://arxiv.org/abs/2301.03441
- 任务：利用约 90 分钟睡眠周期的长程依赖进行自动睡眠分期。
- 方法：高效长序列建模，吸收 whole-cycle sleep information。
- 数据/指标：4 个数据库，多个 EEG setup，包括常规 PSG、in-ear EEG、around-the-ear EEG；报告常规性能与鲁棒性。
- 代码：arXiv 页面声明有源码链接。
- 对本项目的价值：支持“whole-cycle context”作为实验条件，但也提示需要比较计算效率和边界收益。
- 局限：主指标仍偏常规，未把 transition-window error 作为主贡献。
