# SleepEGAN: GAN-Enhanced Ensemble Deep Learning for Imbalanced Sleep Stage Classification

- 年份/状态：2023，arXiv。
- 链接：https://arxiv.org/abs/2307.05362
- 任务：针对睡眠阶段类别不均衡做数据增强与集成学习。
- 贡献：用 GAN 增强少数类样本，并用 ensemble 降低验证/测试异质性带来的估计方差。
- 对方向1的价值：代表 class imbalance 路线，可作为 N1 低样本问题的对照基线。
- 局限：合成少数类样本可能缓解数量不足，但不能直接解决 N1 的标签模糊和评分分歧。
