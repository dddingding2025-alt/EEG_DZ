# Context-Aware Temporal Modeling for Single-Channel EEG Sleep Staging

- 年份/状态：2025，arXiv。
- 链接：https://arxiv.org/abs/2512.22976
- 任务：单通道 EEG 睡眠分期，重点提升 N1 识别。
- 贡献：结合多尺度特征、层级序列学习、class-weighted loss 和数据增强，并报告 N1 F1 提升。
- 对方向1的价值：代表“上下文 + 类别不均衡处理”解决 N1 的近年路线。
- 局限：如果主要在 Sleep-EDF 内部验证，仍不能回答跨数据集 N1 泛化问题。
