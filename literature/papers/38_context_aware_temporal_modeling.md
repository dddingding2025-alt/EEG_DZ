# Context-Aware Temporal Modeling for Single-Channel EEG Sleep Staging

- 年份/状态：2025，arXiv。
- 链接：https://arxiv.org/abs/2512.22976
- 任务：单通道 EEG 睡眠分期，强调 N1 和上下文建模。
- 方法：多尺度特征提取 + temporal modeling + sub-epoch chunk aggregation。
- 数据/指标：SleepEDF；报告 accuracy、macro-F1 和 N1 F1。
- 对本项目的价值：说明 N1 改善仍是当前论文重点；可作为“边界/N1 友好”模型对照。
- 局限：核心贡献仍是模型结构和 N1 指标，不是转期窗口评测协议。
