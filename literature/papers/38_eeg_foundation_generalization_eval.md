# A Multi-Dimensional Framework for Evaluating Generalization in EEG Foundation Models

- 年份/状态：2026，arXiv。
- 链接：https://arxiv.org/abs/2605.28563
- 任务：在多维低资源设置下评估 EEG foundation models 的泛化能力。
- 贡献：强调真实约束包括少标签、传感器减少和参数高效适配；长上下文任务如 sleep stage prediction 更能体现 foundation model 价值。
- 对方向1的价值：为后续比较“专用轻量模型 vs EEG foundation model adapter”提供评测维度。
- 局限：不是专门研究 N1；更适合作为扩展评测参考。
