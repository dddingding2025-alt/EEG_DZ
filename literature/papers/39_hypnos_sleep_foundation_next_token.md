# Hypnos: Next-Token Prediction Learns Generalisable Sleep Physiology Representations

- 年份/状态：2026，arXiv。
- 链接：https://arxiv.org/abs/2606.09605
- 任务：用 next-token prediction 训练多模态睡眠 foundation model。
- 贡献：在大规模 PSG 上学习通用睡眠生理表示，并报告 label-efficient sleep staging。
- 对方向1的价值：说明下一代 sleep foundation model 会影响少标签/跨域设置，但短期更适合作为对比或引用，不适合从零复现。
- 局限：预训练数据、算力和复现成本高；N1 与标签不确定性不是主要问题。
